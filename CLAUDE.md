## Project Overview

This is a personal portfolio website built with Next.js 15, React 18, and TypeScript. It's a single-page application showcasing professional experience, skills, projects, and contact information. The site is deployed as a Progressive Web App (PWA) with internationalization support (French).

## Development Commands

```bash
# Development server (uses Turbopack for faster builds)
npm run dev

# Production build
npm run build

# Start production server
npm start

# Lint code
npm run lint
npm run lint:fix

# Check for unused dependencies and code
npm run knip
npm run knip:fix
```

The sitemap is automatically generated after each build via the `postbuild` script.

## Architecture

### Data Flow Pattern

This application uses a **static JSON-based data architecture**:
- All content data (portfolio projects, experience, skills, etc.) is stored as JSON files in `public/api/`
- Data is fetched client-side using TanStack Query (React Query) via fetchers in `fetchers/`
- Type definitions for all data structures are centralized in `types.ts`

### Directory Structure

```
pages/              # Next.js pages (index.tsx is main single-page app)
  api/              # API routes (sitemap generation)
components/
  containers/       # Section-level components (HeroSection, AboutSection, etc.)
  elements/         # Reusable UI elements (Service, Portfolio, TimelineItem)
  layout/           # Layout components (Header, Footer, Navigation)
  utils/            # Utility components (SectionHeading, Logo, etc.)
fetchers/           # API client and data fetching functions
hooks/              # Custom React hooks
lib/                # Utility functions and helpers
public/api/         # Static JSON data files
settings/           # EmailJS configuration
styles/             # Global SCSS styles
```

### Key Patterns

**Section-Based Architecture**: The main page (`pages/index.tsx`) is composed of named sections using `react-scroll`:
```tsx
<Section name="section-about">
  <AboutSection />
</Section>
```
Navigation uses `react-scroll` to smoothly scroll to sections by name.

**Layout Wrapper**: All pages are wrapped in a `Layout` component that includes Header, Footer, and Navigation.

**Data Fetching**: Components fetch their own data using TanStack Query hooks:
```tsx
const { data: projects } = useQuery({
  queryKey: ['portfolios'],
  queryFn: getPortfolios
})
```

**Type Safety**: All data structures are typed in `types.ts`. When modifying JSON files in `public/api/`, ensure they match the corresponding TypeScript interface.

### Styling

- **Tailwind CSS** for utility-first styling
- **SCSS** for custom global styles (`styles/globals.scss`)
- Tailwind config includes debug screens plugin and custom configuration

### Third-Party Integrations

- **Framer Motion**: Animation library (motion utilities in `lib/motion.ts`)
- **EmailJS**: Contact form submissions (config in `settings/settings.js`)
- **Google reCAPTCHA v3**: Form protection
- **Vercel Analytics**: Page analytics
- **react-scroll-parallax**: Parallax effects
- **Swiper**: Carousel/slider components

## Important Notes

### Data Updates

To modify portfolio content (projects, experience, services, etc.):
1. Edit the corresponding JSON file in `public/api/`
2. Ensure the structure matches the TypeScript interface in `types.ts`
3. The site will fetch updated data on next page load

### Image Configuration

Next.js images use a custom loader with specific device sizes configured in `next.config.js`. External image domains (skillicons.dev, githubusercontent.com) are whitelisted.

### PWA Configuration

PWA is disabled in development mode but enabled in production. Service worker and manifest are generated by `next-pwa` plugin.

### ESLint Configuration

The project uses TypeScript ESLint with standard-with-typescript and Next.js rules. Several strict rules are disabled for pragmatic development (see `.eslintrc.json`).

### French Language

The site is in French - UI text, content, and form labels are all in French. Keep this in mind when adding new features.
