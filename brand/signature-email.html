Installer dans Gmail

  1. Clique sur Copier la signature.
  2. Gmail → roue crantée → Voir tous les paramètres → onglet Général → Signature → Créer.
  3. Colle (⌘V) dans l’éditeur, puis Enregistrer les modifications en bas de page.
  4. Choisis-la dans « Valeurs par défaut des signatures » pour les nouveaux e-mails et les réponses.
